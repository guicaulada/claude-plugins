# claude-plugins

A collection of Claude Code plugins.

## Plugins

| Plugin | Description |
|---|---|
| [otel](plugins/otel/) | OpenTelemetry traces, metrics, and logs from Claude Code hook lifecycle events |

## Installation

Install from this marketplace:

```bash
claude plugin add --marketplace https://github.com/guicaulada/claude-plugins
```

Or install a specific plugin directly:

```bash
claude plugin add https://github.com/guicaulada/claude-plugins --plugin otel
```
