# claude-plugins

A collection of Claude Code plugins.

## Plugins

| Plugin | Description |
|---|---|
| [otel](plugins/otel/) | OpenTelemetry traces, metrics, and logs from Claude Code hook lifecycle events |

## Installation

Add this marketplace:

```bash
claude plugin marketplace add https://github.com/guicaulada/claude-plugins
```

Then install a plugin:

```bash
claude plugin install otel@guicaulada-plugins
```
